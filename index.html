La detección es local. RASTRO no lee el contenido de las webs externas ni puede saltarse las restricciones entre sitios del navegador.

Privacidad: los indicadores se procesan localmente en tu navegador. RASTRO-WEB no tiene servidor propio ni envía consultas a ningún backend. El dominio, IP o URL solo abandona el dispositivo cuando decides abrir una fuente externa. Historial, favoritos y notas quedan en el localStorage de tu equipo.

Limitaciones: no realiza escaneo activo, no evita CORS ni usa proxies ni API keys. Genera consultas y accesos hacia fuentes OSINT públicas para continuar la consulta manualmente.
